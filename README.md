# holmgds-gui.github.io

Arquivos de apoio do login com Google do [Muscle Atlas](https://holmgds-gui.github.io/atlas-muscular/).

A pasta `__/auth/` tem a página de login do Firebase Authentication (copiada de `muscle-atlas-e1a56.firebaseapp.com/__/auth/`), servida no mesmo endereço do app. Assim o login funciona em navegadores que bloqueiam dados de outros sites (Safari, app instalado no iPhone etc.). `__/firebase/init.json` é a configuração pública do projeto Firebase.

Não apague nem mova esses arquivos: o login do app depende deles.
